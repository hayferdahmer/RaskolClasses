# RUNBOOK — RaskolClasses

Операторский справочник для администратора сервера «РАСКОЛ | ДВЕ КОРОНЫ».
Три раздела: аварийные процедуры, тюнинг баланса без пересборки,
чек-лист оператора перед ивентом/осадой.

Версия: 1.6.14 · Обновлено: 2026-09-10

## 1. АВАРИЙНЫЕ ПРОЦЕДУРЫ

Используются при нештатных ситуациях. Все процедуры — без сборки jar,
только правка конфига + `/rc reload` или замена файла.

### 1.1 Откат jar на предыдущую версию

**Когда:** свежий патч сломал бой/касты/Книгу класса, нужно срочно вернуть
рабочую версию без отладки.

**Порядок:**
1. `/stop` (graceful shutdown через панель или команду) — плагины сохранят
   состояния через `onDisable`.
2. Сделай резервную копию текущего jar:
   ```bash
   cp plugins/RaskolClasses/raskol-classes-1.6.X.jar \
      plugins/RaskolClasses/raskol-classes-1.6.X.jar.broken
