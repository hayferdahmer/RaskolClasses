# RaskolClasses

Плагин активных способностей для сервера «РАСКОЛ | ДВЕ КОРОНЫ».
Пять классов · десять специализаций · ставящиеся мины/варды · королевские титулы.

**Paper 1.21.4 · Java 21 · зависимости: LuckPerms, AuraSkills, PlaceholderAPI, RaskolCore, Towny, AuthMe (опц.)**

## Команды

- `/rc` — информация о классе игрока
- `/rc 1–5` — каст классовых способностей
- `/rc 6` — каст активки специализации
- `/rc 7` — постановка инсталляции
- `/rc menu` — Книга класса (всё классовое в GUI)
- `/rc reload` — перезагрузка конфигов
- `/rc debug [player]` — диагностика

## Архитектурные принципы

- **Единая точка VFX/SFX** — `FxService`, индекс реестра + алиасы, валидация на старте и reload.
- **Все касты через одну воронку** — `AbilityRegistry.castOn` / `SpecActiveCaster.tryCast` / `InstallationService.tryPlace`: гейты auth/creative/краёв применяются единожды на канал.
- **Локализация без пересборки** — все пользовательские строки в `messages.*`, `addDefault` + `copyDefaults` дописывают ключи сами.
- **Производительность по умолчанию** — звуковой бюджет/тик, адаптивные свипы, консолидированные purge-таски, dirty-rendering HUD.
- **Без deprecated API** — `Attribute.MAX_HEALTH`, `Registry.SOUNDS`, `Registry.PARTICLE_TYPE`, `Registry.ATTRIBUTE`, Paper data-components для durability-бара свитков.

## Зависимости

| Плагин | Роль | Статус |
|---|---|---|
| LuckPerms | источник класса (фолбэк паспорта Core) | required |
| AuraSkills | профильные скиллы для unlock-лестниц | soft |
| PlaceholderAPI | плейсхолдеры `%raskolclasses_*%`, `%raskolcrown_*%` | soft |
| RaskolCore | паспорт класса, экономика респеца | soft |
| Towny | запрет инсталляций в клеймах | soft |
| AuthMe | гейт для неаутентифицированных (рефлексия, fail-open) | soft |

## Заметки разработчику

- **CI-гейт:** любые deprecated API валят ран — не использовать.
- **Артефакт:** `raskol-classes-<version>.jar` (finalName = artifactId + version).
- **Политика тегов:** теги ставим на заморозке минорной ветки (v1.5.10); патчи 1.5.x тегами не сопровождаем.
- **История:** `CHANGELOG.md`.
- **Соглашение по версиям:**
  - `1.5.x` — патчи в заморозке 1.5.x (только исправления, без новых фич);
  - `1.6.0` — следующая минорная ветка с новыми фичами;
  - `1.5.10.1` — хотфикс критического бага после заморозки.
