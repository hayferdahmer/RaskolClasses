# RaskolClasses — классовая система «РАСКОЛ | ДВЕ КОРОНЫ»

Paper 1.21.x · Java 21 · линия 1.6.x · **ветка заморожена с 1.6.15**

Пять классов с ресурсами и активными способностями, специализации,
инсталляции, королевские вкусы (короны/титулы/ауры) и полная боевая
математика: четыре вида урона, сопротивления, модификаторы и рубильники
баланса — всё настраивается без пересборки.

## Состав системы

- **Классы:** Воин, Охотник, Жрец, Маг, Разбойник. Ресурс 0–100 с правилами
  регена по классам (тиры маны мага, декей ярости воина вне боя, концентрация
  охотника только вне боя, свет жреца всегда, энергия разбойника).
- **Способности:** слоты 1–5 (лестница открытия 1/10/25/50/75), свитки в хотбар
  (ПКМ — каст в себя, ЛКМ по союзнику — точечный каст жреца), полоска
  перезарядки на свитке.
- **Специализации:** две на класс, выбор с 40 уровня профильного скилла,
  активка в слоте 6, свитки спеков, платный респец с двойным подтверждением.
- **Инсталляции:** ставящиеся мины/варды (слот 7), TTL, лимиты, килл-кредит
  владельцу, notify владельцу.
- **Короны:** Рассвет/Вальрадис — титулы классов и партикл-ауры.
- **Бой:** типы урона physical/magic/hybrid/true, резисты по классам,
  модификаторы (эффекты, спек-пассивки, динамический mana-soaked),
  PvP-кап, миры без резистов, friendly-fire гейт, LOS для AoE.
- **Диагностика:** `/rc debug` (разбивка резистов + симулятор урона),
  `/rc health` (метрики живого сервера), `/rc selftest` (7 групп проверок).
- **Надёжность:** атомарные сейвы хранилищ с `.bak` и автофолбэком, автосейв,
  валидатор конфига, NaN-гарды, санитизация устаревших свитков.

## Требования и совместимость

- Paper 1.21.4+ (целевой билд), Java 21.
- softdepend (каждый опционален, деградация graceful):
  LuckPerms (классы/спеки), AuraSkills (уровни скиллов), PlaceholderAPI
  (плейсхолдеры), RaskolCore (паспорта классов), Towny (клеймы инсталляций),
  AuthMe (гейт до логина).

## Установка

1. `mvn -B clean package` → `target/raskol-classes-<version>.jar`.
2. jar в `plugins/`, рестарт сервера.
3. `config.yml` и `specs.yml` создаются автоматически; правки применяются
   через `/rc reload` без рестарта.
4. Хранилища: `cooldowns.yml`, `spec-choices.yml` — атомарная запись,
   `.bak`-копии, автосейв каждые `storage.autosave-minutes`.

## Команды и права

| Команда | Право | Назначение |
|---|---|---|
| `/rc` | — | сводка игрока: класс, ресурс, резисты, корона, спека, способности |
| `/rc 1–5` | — | каст способности слота |
| `/rc 6` | — | каст активки специализации |
| `/rc 7` | — | постановка инсталляции своего класса |
| `/rc menu` | — | Книга класса (3 вкладки, живое обновление) |
| `/rc reload` | `raskolclasses.admin` | перезагрузка конфигурации |
| `/rc debug [player]` | `raskolclasses.debug` | разбивка резистов, симулятор урона, КД, эффекты, fx |
| `/rc health` | `raskolclasses.debug` | MSPT/TPS, размеры карт, бюджет звуков, purge, аптайм |
| `/rc selftest` | `raskolclasses.debug` | headless-самотестирование, PASS/FAIL-список |

## Соглашение по версиям

- **1.6.x** — линия стабилизации. **С 1.6.15 ветка заморожена.**
- **Хотфиксы 1.6.15.1+** — только критические баги (потеря данных, краш,
  эксплуат-уязвимость). Никаких новых механик и баланс-правок по умолчанию.
- **1.7.0** — весь геймплейный контент: ультимативные способности, пати-бонусы,
  интеграции MythicMobs/AuraSkills-резисты, миграция `FxService` с
  deprecated `Sound#getKey` на актуальный Paper API.
- Теги: `v<version>` на каждый релиз, `v1.6.15.N` на хотфиксы; артефакт
  прикрепляется к GitHub Release.

## Заметки разработчику

- Сборка: `mvn -B clean package`; артефакт `target/raskol-classes-<version>.jar`.
- CI: workflow «RaskolClasses Build» на каждый пуш; красный ран = блок релиза.
- Deprecation-политика: варнинги допустимы только с зафиксированным техдолгом.
  Текущий долг: `FxService` использует `Sound#getKey()` (deprecated for removal) —
  миграция запланирована в 1.7.0; новых deprecated-вызовов не добавлять.
- Политика WARNING: однострочные сообщения без стектрейсов; стек только там,
  где без него не найти причину (коррупт хранилища в SafeStorage).
- Бэклог 1.7.0 ведётся отдельным списком; в 1.6.x не переносится ничего,
  кроме критических хотфиксов.
