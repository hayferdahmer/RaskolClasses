# CHANGELOG — RaskolClasses

Формат: [версия] — дата — имя. Секции Added / Changed / Fixed.

## [1.4.0] — 2026-09-02 · «Специализации и Короны»

### Added
- **Специализации:** две на класс, выбор на 40 уровне профильного скилла
  (`/rc spec`, GUI), одна на всю жизнь; хранение `spec-choices.yml`;
  LP-нода `raskolclasses.spec.<id>` для TAB.
- **Боевая механика спеков:** 10 пассивок (постоянно) и 10 активок
  (слот 6: `/rc 6`); атрибутные бонусы (Страж: +2 брони, Следопыт: +10% скорости).
- **Свитки спеков:** `/rc bind 6` — свиток NETHER_STAR, ПКМ — каст;
  свиток чужой спеки не работает.
- **Визуал ловушки охотника:** ItemDisplay «капкан» (tripwire hook ×2.2)
  на земле + партиклы + звук трипвайра; кольцо снежинок у «Кольца льда»,
  сердечки в «Святилище».
- **Платный респец:** `/rc respec` + подтверждение 30 с; цена 250 + 10×уровень;
  списание через economy-контракт RaskolCore (Vault/Essentials), деньги сжигаются;
  админ (`raskolclasses.admin`) — бесплатно; при недоступной экономике — блок.
- **Королевские вкусы:** титулы классов по короне из паспорта Core
  (Рассвет/Вальрадис), партикл-аура (END_ROD / SOUL_FIRE_FLAME), напоминание
  титула при входе; плейсхолдеры `%raskolcrown_crown% / _title% / _faction%`.

### Fixed
- Paper 1.21.4: атрибуты через `Registry.ATTRIBUTE` (констант GENERIC_* нет);
  `spawnParticle` на не-игроке — только через `World`; порядок аргументов
  `Transformation` = (translation, leftRot, scale, rightRot).
- EconomyHook: ленивый резолв реестра Core (баланс респеца показывал 0).
- Восстановлена регистрация SpecBindListener (бинд свитка спеки).
- «Мороз»: замедление ложится и на мобов, не только на игроков.
- `specs.yml`: самовосстановление из шаблона при побитом файле.
- Гейт уровня: админ-байпас для теста; не блокирует выбор, если AuraSkills
  недоступна (иначе фича молча мертва при любом сбое скилл-хука).

### Changed
- `/rc` usage: `[1-6|menu|hud|reload|debug|bind|spec|respec]`.
- `/rc` (info) и `/rc debug` показывают корону и титул.

## [1.3.2] и ранее — история разработки

База классов: ресурсы 0–100 с реген-правилами, активки слотов 1–5 (лестница
1/10/25/50/75), свитки 1–5 (ПКМ/ЛКМ), HUD action-bar, босс-бары эффектов,
ready-notify, AuraSkills ×1.5 профильным деревьям, чтение класса из паспорта
RaskolCore (LP — фолбэк).
