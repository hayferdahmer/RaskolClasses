# 🤝 Участие в разработке RaskolClasses

RaskolClasses — проект с **открытым для чтения кодом** (source-available), а не открытое ПО.
Код под [RASKOL Proprietary License v2.0](LICENSE) ([русский текст](LICENSE.ru.txt)).
Вклад принимается, но правила здесь жёсткие и нужны, чтобы авторские права на проект
оставались у одного правообладателя.

## Что можно

- читать код, проверять его и сообщать об ошибках (уязвимости — по [SECURITY.md](SECURITY.md), не через публичные issues);
- форкнуть репозиторий **внутри GitHub** и открыть pull request;
- собрать и запустить плагин **локально, в закрытой тестовой среде**, только чтобы проверить свой вклад (п. 2.3 Лицензии).

## Чего нельзя

Запускать плагин на своём сервере, публиковать его копии и форки вне GitHub, переносить код в другие проекты, обучать на нём модели,
использовать название и графику проекта. Полный перечень — в разделе 3 Лицензии.

## Условия вклада (обязательно)

Открывая pull request, issue с кодом или любой иной вклад, Вы подтверждаете, что прочитали и принимаете
[Соглашение контрибьютора](docs/legal/CONTRIBUTOR-AGREEMENT.md), в частности:

1. Вы автор вклада, либо у Вас есть право его передать; вклад не нарушает чужих прав и не содержит чужого кода без совместимой лицензии (код под GPL и подобными лицензиями не принимается).
2. Вы передаёте Лицензиару исключительные права на вклад (или, если это невозможно по закону, исключительную лицензию), как описано в соглашении.
3. Лицензиар не обязан принять вклад, указать Ваше авторство или заплатить за него.

**Команда проекта** (постоянные участники) подписывает соглашение отдельным документом, до первого слияния своего кода.
Pull request без отметки о принятии соглашения не рассматривается. Заметный по объёму код принимается только после подписания соглашения отдельным документом (право РФ требует письменной формы).

## Технические требования

Как в шаблоне pull request: `mvn -B verify` зелёный, `/rc selftest` проходит, запись в `CHANGELOG.md`,
каждый новый файл начинается с заголовка лицензии (его добавляет `python tools/apply-license-header.py`).
